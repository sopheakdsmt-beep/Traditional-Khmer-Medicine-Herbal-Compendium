# បណ្ណាល័យឱសថបុរាណ និងរុក្ខជាតិឱសថ

A tablet compendium of Cambodian medicinal plants for traditional healers (គ្រូខ្មែរ), pharmacists, herbalists, and botany researchers. The atlas keeps a high-resolution plate beside the preparation, and the formula tray flags herbs that Khmer humoral practice does not boil together.

The doses are household study notes drawn from widely recorded traditional use. They are not prescriptions. Pregnancy, infants, and anyone on medication need a clinician or a qualified healer before use.

## Use the atlas

- Search by ailment (`គ្រុនក្តៅ`, fever) or by local, Roman, English, or Latin name (`ស្លឹកបាស`, `plai`, `Curcuma`).
- Switch a plate between the living habit and a labeled cross-section.
- Read the preparation in two columns: method on one side, dose and warning tags on the other.
- Add plants to the formula tray. Heating herbs (ខ្ញី, រំដេង, ម្រេច) are marked against cooling herbs (ស្ដៅ, ផ្ទះមហា, ស្លឹកបាស).

## Run

```bash
npm install
npm test
npm run dev
```

Open the dev server on a tablet-width window (about 1100px wide) for the three-pane layout.
